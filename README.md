# Šolski Dogodki (SERŠ Event Hub)

Spletna predstavitev skupinskega projekta: koledar šolskih dogodkov in prijave na delavnice. Stran predstavi tudi izmišljeno persono 17-letnega dijaka Jana Klajnoseka.

## Predogled

Odprite [spletno stran na GitHub Pages](https://dzenadhidosers.github.io/DN1/). Predogled je mogoče odpreti tudi lokalno z datoteko `index.html`.

Za samodejno osveževanje v namiznem VS Code lahko uporabite priporočeno razširitev Live Server in kliknete **Go Live**. Predogled razširitev v `vscode.dev` je odvisen od dovoljenj brskalnika za service worker; za zanesljiv ogled uporabite zgornjo povezavo do GitHub Pages.
